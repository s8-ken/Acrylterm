# Acrylterm 要件・設計メモ(v0.2)

最終更新: 2026-10-14

## 目的

自宅の Mac mini へ Tailscale 経由で SSH 接続するための Android ターミナルアプリ。Termius の致命的な不満点である「日本語入力ができない」を解消する。herdr の利用を前提に設計する。

## 主な利用シーン

- Android 端末 →(Tailscale)→ 自宅 Mac mini に SSH 接続する
- Mac mini 上の herdr で、複数のペインや複数の AI エージェント(Claude Code など)を操作・監視する

## 要件(MVP、すべて実装済み・実機での確認待ち)

1. **SSH クライアント**
   - パスワード認証(keyboard-interactive へのフォールバックあり)と公開鍵認証
   - ホスト鍵の検証(初回接続時に確認し、鍵が変わったら警告)
2. **日本語入力 (IME)**
   - 変換中の文字列をカーソル位置に表示し、確定した文字列だけを UTF-8 で送信する
   - 予測変換を止める「直接入力モード」に切り替えられる
3. **SSH 鍵管理**
   - Ed25519 と RSA 4096 の鍵を生成できる
   - 既存の鍵をインポートできる(OpenSSH / PEM / PKCS#8 / PuTTY 形式、パスフレーズ付きも可)
   - 公開鍵をコピー・共有できる
   - 秘密鍵は Android Keystore(AES-GCM)で暗号化して保存する
   - 鍵ごとに、使用時の生体認証を必須にできる
   - ホストごとに使う鍵を割り当てられる
4. **herdr 連携**
   - 画面表示:herdr のタブとペインをアプリのネイティブ機能として表示する(マルチタブ / マルチペイン)
     - ペインごとに端末を割り当て、herdr のレイアウトの比率で並べる。区切り線のドラッグで比率を変える
     - 互換モードでは、PTY 上で herdr の TUI をそのまま表示する(スマホ幅では herdr 側がモバイル向けのレイアウトになる)
   - タッチ操作:タップでフォーカス移動とクリック、ダブルタップでズーム、2 本指の水平スワイプでタブ切替、ピンチで文字サイズ。互換モードではタッチを SGR マウスイベントに変換する
   - ネイティブのドロワー:ワークスペース → タブ → ペインの一覧とエージェント状態を表示する
     - タップでフォーカス切り替え
     - ペイン内容のプレビューと返信
     - タブ・ワークスペース・ペインの作成、名前変更、閉じる操作(タブは取り消し可能)
     - エージェントのタブの作成、herdr のワークツリーの作成と削除、herdr セッションの切り替え
   - 入力待ちのペインに返信バー(承認 / 選択肢 / キャンセル / 作成)
   - ホストに herdr が無いときは通常のシェルを開く
   - 通知:エージェントが入力待ちや完了になったら Android の通知を出す。タップすると該当ペインへ移動する
5. **Tailscale 内蔵(オプション)**
   - tsnet をユーザースペースで動かすので VPN 枠を使わない
   - 画面からログイン(認証 URL または auth key)し、tailnet 上のデバイスを一覧から選んでホストに設定できる
6. **モバイル向け補助キーバー**
   - ESC / TAB / CTRL / ALT(1 回で次の 1 キー、2 回で HOLD)、方向キー(フリック、中央で Enter、保持でリピート)、記号、HOME/END/PGUP/PGDN、キーボード表示の切り替え
   - ^B(herdr のプレフィックス)は互換モードだけに出す
7. **バックグラウンドでの接続維持**:フォアグラウンドサービスで接続を維持する

## 追加で実装したもの

- **Mosh**:ホストごとのオプション。ペインごとに mosh-server を起動し、回線が切り替わってもペインを維持する。失敗時は SSH に戻る(詳細は architecture.md)
- **テキスト選択とコピー**:長押しでアプリ側の選択を始め、コピー / 貼り付け / すべて選択
- **スクロール**:シェルのペインは herdr から履歴を取り寄せて表示。TUI の上下の固定帯はスクロール中も固定する
- **外観**:色プロファイル(5 種のプリセットとカスタム)、背景の透明度、壁紙のぼかし
- **Lua 拡張**:上級者向けのオプション。同梱テンプレート(既定はすべて off)あり(詳細は extensions.md)

## 決定事項

- 正式名は Acrylterm（アクリルターム）(2026-10-14、ユーザー判断。旧名 Veildeck。`applicationId` とパッケージ名は据え置き)
- 最初から herdr 前提で作る(2026-10-12、ユーザー判断)
- ビルドは Mac の Android Studio で行う
- herdr は 0.9.3 に更新し、0.9 系を主な対象にする。0.8 系との互換も保つ
- 2026-10-12 Mac の herdr を 0.9.3 に更新(検証済み)
- 主な技術:Kotlin + Jetpack Compose
  - ターミナルエミュレータ:Termux の terminal-emulator を取り込んで使う
  - SSH:sshj 0.41
  - Tailscale:tsnet を gomobile で組み込む
- アプリ ID:`com.shibaken.androidterminal`
- 動作環境:minSdk 26、targetSdk 35、arm64
