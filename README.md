# androidTerminal

自宅の Mac mini に Tailscale 経由で SSH 接続するための Android ターミナルアプリ。

- **日本語入力**:IME の未確定文字列(変換中の文字)をカーソル位置に表示し、確定した文字列だけを送信する
- **Cyan Veil UI**:黒緑・シアンの配色、丸みのあるカードと操作ボタン。外観設定でターミナル背景の透明度と壁紙のぼかしを調整
- **Lua 拡張**:ホスト一覧の「拡張スクリプト」で作成・編集。ホストごとに有効化し、補助キー・コマンド・クイック返信を追加
- **herdr 連携**:herdr のソケット API を SSH 経由で直接操作する
  - ドロワーにワークスペース・タブ・ペインとエージェント状態を表示し、タップで切り替え
  - 分割・ズーム・ペインを閉じる操作
  - ペイン内容のプレビューと返信
  - エージェントが入力待ちになったら Android 通知
- **SSH 鍵管理**:Ed25519 / RSA の生成、既存鍵のインポート、公開鍵のコピー・共有
  - 秘密鍵は Android Keystore で暗号化して保存
  - 使用時に生体認証を要求する設定も可能
- **Tailscale 内蔵**:`tsnet` をアプリに組み込む(VPN 枠を使わないので公式アプリと併用可)。後から追加できるオプションで、なくてもビルドできる

設計と調査メモは `docs/` にあります。

- `docs/requirements.md`:要件
- `docs/architecture.md`:構成
- `docs/herdr-api.md`:herdr ソケット API のリファレンス

## ビルド(Mac / Android Studio)

1. Android Studio でこのフォルダを開く(Gradle 同期で依存関係が自動取得されます)
2. 実機をつなぎ、`app` を Run
   - コマンドラインの場合は `./gradlew :app:installDebug`

この時点で、端末側の Tailscale アプリ(VPN)を使えば接続できます。その場合はホスト設定で「Tailscale 経由」をオフにしてください。

### Tailscale を内蔵する(任意)

```sh
# 事前に Android Studio > SDK Manager > SDK Tools で「NDK (Side by side)」をインストール
./tsbridge/build.sh        # app/libs/tsbridge.aar を生成
```

生成後にアプリを再ビルドすると、Tailscale 画面からログインできるようになります。初回は gomobile と tailscale.com の取得のため数分かかります。

## Mac 側の準備

- **リモートログイン**:システム設定 > 一般 > 共有 > 「リモートログイン」をオン
- **公開鍵の登録**:アプリの「SSH 鍵」画面で鍵を生成し、公開鍵をコピーして Mac の `~/.ssh/authorized_keys` に追記する
- **herdr**:0.9.3 を推奨・検証済み(0.8 系でも動作します)
  - 更新は `herdr update`。更新後は `herdr integration install claude` / `herdr integration install codex` を再実行してください
  - herdr のサーバーが起動していなくても、ログイン後に `herdr` を自動実行するので立ち上がります
  - 実行するコマンドはホスト設定で変更できます
- **sshd の設定**:`AllowStreamLocalForwarding` を `no` にしていないこと(デフォルトは yes)

## 操作

マルチタブ / マルチペイン(PANES)モードの操作です。

| 操作 | 動作 |
|---|---|
| ペインをタップ | フォーカス中なら通常のタップ(クリック)、別のペインならそのペインへ移動 |
| ペインをダブルタップ | ズームの切り替え |
| ペインを長押し→指を滑らせて離す | 放射状メニュー(右に分割 / 下に分割 / ズーム / 閉じる / 名前変更)。中央で離すとキャンセル |
| 区切り線をドラッグ | ペインの大きさを変更 |
| 縦ドラッグ | スクロール |
| 2 本指で左右スワイプ | 前 / 次のタブ |
| ピンチ | 文字サイズ変更(全ペイン共通) |
| 下部のタブバーをタップ / 左右スワイプ | タブの切り替え |
| 下部のタブバーを上スワイプ(または格子アイコン) | 全タブの一覧。カードをタップで移動。長押しで編集モードに入り、閉じるボタンまたは上スワイプで閉じる(確認あり)。入力待ちの数がアイコンに出ます |
| 入力待ちのペイン | ペイン下端に返信ボタン(承認 / 選択肢 / キャンセル / 作成)が出ます |
| タブバーの鉛筆アイコン | 作成欄(複数行・日本語変換・音声入力)から、フォーカス中のペインへ送信 |

- 幅が足りない(1 ペイン 40 桁未満)ときと、ズーム中は、フォーカス中のペインだけを表示します
- 左端の ☰ でワークスペースのドロワー、右端の + で新しいタブ(入力待ちのタブには `!` が付きます)
- 操作の失敗は画面下部にスナックバーで表示されます
- 補助キーバーの ⌨(キーボード切替)は左端に固定されています。キーはフォーカス中のペインに送られます
- CTRL / ALT はタップすると次の 1 キーにだけ効きます
- メニューの「直接入力(変換なし)」は、コマンド入力時に予測変換を止めたいときに使います

互換モード(旧 TUI 表示)や通常シェルでは、タップ=クリック / キーボード表示、縦ドラッグ=スクロール、長押し→ドラッグ=マウスドラッグ(互換モードのみ)、ピンチ=文字サイズです。互換モードでは下部の操作バーと補助キーの `^B`(Ctrl+b)も使えます。

## 外観設定

ホスト一覧またはターミナル上部の調整アイコンから開きます。背景の透明度は 0–100% で、0% は不透明、100% はアプリ内の壁紙が完全に見える状態です。文字・カーソル・明示的な ANSI 背景色は薄くなりません。プリセットは 0% / 28%(おすすめ) / 55% です。

設定は「この外観を適用」で保存されます。戻る操作では変更を破棄します。「背景をぼかす」は壁紙だけに適用され、Android 12 未満ではグラデーションをなだらかにして近い効果を出します。

デザイン・検証の詳細は [design/cyan-veil/README.md](design/cyan-veil/README.md) を参照してください。
